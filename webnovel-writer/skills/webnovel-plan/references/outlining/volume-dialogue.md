# 卷级规划对话（Step 1.5 - Step 1.6）

卷纲生成前的强制对话阶段。目标：在落任何卷级产物之前，把「必须由作者拍板」的卷级决策收敛成一份决策卡；未通过闸门不得进入生成阶段。

## 一、边界

- 只讨论卷级决策；不拆章号，不产出章级执行字段或章级合同参数。
- 对话阶段唯一允许写入的文件是 `大纲/第{volume_id}卷-规划讨论.md`（决策卡）。不写 `设定集/`、`大纲/总纲.md`、卷级产物、`.story-system/` 或正文。
- 决策卡是作者资产：只增量更新条目，禁止整文件重写。

## 二、10 项必答议题

| # | 议题 | 为什么必须作者拍板 | 建议默认（可被作者直接接受） | 落点产物 |
|---|------|-------------------|--------------------------|---------|
| 1 | 卷核心冲突 | 决定整卷主线走向，无法从总纲反推作者意图 | 总纲该卷最晚出现的对抗关系 | 节拍表 + 详细大纲 |
| 2 | 卷末高潮 | 决定张力落点与爽点兑付方式 | 总纲该卷的高潮句 | 节拍表 + 总纲写回 |
| 3 | 卷末承接（下一卷锚点） | 写回总纲，是下一卷规划的前提 | 本卷高潮后最未解决的那条线 | 总纲写回 |
| 4 | 中段反转 | 节拍表必填项；确无反转须给理由 | 由核心冲突反推的身份或立场反转 | 节拍表 |
| 5 | 至少 3 次递增危机 | 决定节奏与代价升级曲线 | 按倒计时倒推危机顺序 | 节拍表 |
| 6 | 时间体系与本卷跨度 | 时间线硬约束；写错会导致全卷章内时间返工 | 沿用上一卷时间体系 | 时间线 |
| 7 | 倒计时事件 | 与危机递增绑定；不明确会出现算术不一致 | 无倒计时则显式写「不适用」 | 时间线 |
| 8 | Strand 分布与爽点密度 | 决定卷内 quest / fire / constellation 配比 | 沿用上一卷配比 | 详细大纲 |
| 9 | 伏笔埋收与开放环 | 决定哪些线本卷收、哪些留到后续 | 只收本卷内已铺垫两次以上的线 | 详细大纲 + 总纲写回 |
| 10 | 新增设定边界与本卷禁区 | 约束写回范围，防止越权改 canon | 只补不改；禁区默认不含能力跳级与身份提前曝光 | 设定写回 + 全部产物 |

首卷没有「上一卷」时，第 3、6、8 项的建议默认改为按总纲与创意约束推导。

## 三、每轮话术模板

每轮固定三段：先给建议，再给有限选项，最后给结束开关。

```text
本轮议题：{议题名}（{已完成}/{总数}）
- 我的建议：{建议值}
- 理由：{为什么这样最省返工}
- 风险：{选它会在哪一章付代价}
请选：
  A. {候选一}
  B. {候选二}
  C. 按你的建议来
  D. 不再讨论，结束对话
```

规则：

1. 每轮 3-5 个议题，只问当前没有结论的项。
2. **无轮次上限**：作者可以一直讨论到满意为止。
3. **每轮必须带「不再讨论」选项**；作者选择后立即结束对话，未决项写 `待定` 并进入闸门判定。
4. 必须先给建议再问；禁止只抛开放问题（例如「你想怎么写这一卷？」）。
5. 每轮结束增量更新决策卡，保证中断可恢复。
6. 作者答复与总纲 / 设定冲突时，当场记 `BLOCKER` 并请作者裁决，不带入生成阶段。

## 四、决策卡模板

文件：`大纲/第{volume_id}卷-规划讨论.md`

```markdown
# 第{volume_id}卷 规划讨论（决策卡）

- 状态：对话中 / 已确认
- 议题总数：10
- 未决项：0
- BLOCKER：0
- 对话轮次：0（无上限）

## 一、必答议题结论

| # | 议题 | 结论 | 来源 |
|---|------|------|------|
| 1 | 卷核心冲突 | ... | 作者指定 / 作者接受建议 |
| ... | | | |

## 二、BLOCKER 与裁决

| 项 | 冲突内容 | 裁决 |
|----|---------|------|
| | | |

## 三、本卷禁区

- ...

## 四、作者确认记录

- 确认时间：{timestamp}
- 确认原文摘要：{作者确认回复的摘要}
```

字段口径：

- `来源` 只允许 `作者指定` / `作者接受建议`；未决一律写 `待定`。
- `状态` 在作者确认前为 `对话中`，确认后改 `已确认`；闸门只认 `已确认`。
- **禁止占位标记**：决策卡不得出现 `[待...]`、`（暂名）`、`{占位}` 这三类串。原因：`大纲/` 下所有 md 会被 `placeholder-scan` 递归扫描，并会被写前门禁按章节关键实体匹配 → 占位标记会变成阻断正文写作的假 blocker。未决项一律写 `待定`。

## 五、闸门清单（进入生成阶段前逐项核对）

1. 决策卡存在且非空。
2. 10 项必答议题全部有结论，`未决项 = 0`。
3. `BLOCKER = 0`，冲突均已裁决。
4. 作者做过一次显式确认，`状态` 为 `已确认`。
5. 决策卡不含占位标记，也不含章级执行字段。

任一不满足 → 不落任何卷级产物，只保留决策卡，并在报告中说明卡点、已完成内容与恢复方式。

## 六、中断恢复

- 重跑规划：先读决策卡，展示「已决 / 未决」清单，只问未决项，不重问已决项。
- 决策卡已 `已确认` 但卷级产物缺失 → 直接进入生成阶段，不重复讨论。
- 决策卡存在但总纲或设定已变更 → 只对受影响议题重新提问，其余沿用。
- 作者中途放弃 → 决策卡保留，报告标为「需要你处理」，不得自动补默认值后继续生成。

## 七、禁令

1. 对话阶段不写 canon 文件（见第一节边界）。
2. 不整文件重写决策卡；只更新对应条目与统计行。
3. 不用章级执行字段描述议题（逐章目标、结构化节点、章级合同参数一律不出现）。
4. 不提供「跳过对话」开关；作者若表示按建议来，则把建议值记为 `作者接受建议`，闸门照常判定。
